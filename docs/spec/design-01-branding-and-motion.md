## The engine (my call, which he delegated in the note above; labeled: mine)

- **GSAP 3.15 is the motion engine.** Every animation action is a modular timeline factory: one file per verb or moment, with named labels, every duration and ease read from the tokens, and seekable.
- **`motion` springs** handle continuous, interruptible values (eyes following you, the tilt). DialKit already depends on `motion`.
- **Why GSAP:**
  - It's the industry standard for choreographed UI motion.
  - Its timelines are deterministic and seekable, which helps DialKit scrubbing and frame-exact demo video renders.
  - Its plugins cover his moments.
  - It's the best-documented engine in models' training data, so AI-prompted code comes out right the first time.
- **Textures:** shader textures (grain, moss) render on small canvases, and only while visible. There are no WebGL scenes or characters (his 2.5D pick).
